# Definition of Done

Marcar `N/A` con motivo cuando no aplique.

- [ ] Objetivo y criterios de aceptación cumplidos.
- [ ] Alcance y no objetivos respetados.
- [ ] Contratos actualizados y compatibles o versionados.
- [ ] Decisiones importantes registradas.
- [ ] Dominio e invariantes válidos.
- [ ] Persistencia y migraciones probadas.
- [ ] Jobs idempotentes, cancelables y recuperables.
- [ ] Errores estructurados y recuperación accionable.
- [ ] UI comprensible y con una acción primaria.
- [ ] Preview real disponible para decisiones visuales.
- [ ] Estados vacío/carga/proceso/revisión/éxito/sin resultados/error/interrupción/cancelación cubiertos según aplique.
- [ ] Teclado, foco, contraste, ARIA y comunicación no basada solo en color.
- [ ] Unit tests relevantes pasan.
- [ ] Integration tests relevantes pasan.
- [ ] Smoke tests relevantes pasan.
- [ ] E2E relevante pasa.
- [ ] Regression test incluido para bug significativo.
- [ ] Format pasa.
- [ ] Lint pasa.
- [ ] Typecheck pasa.
- [ ] Build pasa.
- [ ] `git diff --check` pasa.
- [ ] Documentación y estado actualizados.
- [ ] Capturas incluidas cuando cambia UI.
- [ ] No hay TODO/FIXME temporales nuevos sin decisión registrada.
- [ ] No se introdujo código muerto ni abstracción especulativa.
- [ ] Archivos modificados reportados.
- [ ] Pruebas omitidas justificadas.
- [ ] Migraciones y backups reportados cuando existen.
- [ ] Dos loops completados sin rediseño fuera de alcance.
- [ ] No hubo commit/push sin autorización aplicable.

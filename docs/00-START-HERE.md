# FacelessCreator — Inicio

FacelessCreator es la estación de **producción long horizontal** faceless del ecosistema.

## Rol en el ecosistema

| App | Rol |
|-----|-----|
| **YouToMagic** | Análisis, guion, export `Documents/FacelessStudio/packages` |
| **VisuaLibrary** | Imágenes / Library / Review |
| **FacelessCreator (esta app)** | Import package → TTS → montaje → MP4 |
| **VigilCut** | Shorts / vertical |

Mapa canónico: `YouToMagic/docs/18-ECOSISTEMA-APPS.md`.

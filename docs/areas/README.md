# Documentación por área

Esta carpeta reduce el contexto necesario por tarea. Sus archivos describen la implementación existente y enlazan a las autoridades de Foundation 0; no las sustituyen.

- [Backend](backend/README.md): Python, SQLite, jobs, API y recuperación.
- [Frontend](frontend/README.md): shell web local, estado y estaciones UX.
- [Multimedia](multimedia/README.md): FFmpeg, fixtures, preview y exportación.
- [QA](qa/README.md): ejecución y distribución de pruebas.

Una tarea debe leer `PROJECT_STATUS.md`, el área afectada y las autoridades enlazadas. Si cruza un contrato, debe leer ambos lados.
